# Support

Public support channel: <https://vibewalkie.app/support>.

Before requesting help, confirm that both apps are current, on the same Wi-Fi network and that Accessibility is granted to the companion. In Roaming mode, also confirm that Tailscale is connected on both devices, that they share the same tailnet or the Mac is shared, and that ACLs allow port 54389. Resetting the TLS identity requires pairing again.

A support request may include app versions, device models, operating-system versions and observed steps. It must never include dictated text, a still-valid QR code, private key, distribution certificate, UDID or a screenshot containing confidential data.

The latest stable release receives fixes. Support for forks and unofficial builds is provided on a best-effort basis by their distributor.
